自主对局

agent 自己读局面、出行动、结算、开下一手，全程不需要点按钮。跑完直接给出 bb/100 ± SE。本版把变化检测门控从频率类统计扩到尺度类连续统计。v1.21 的门控只覆盖翻前/翻后的频率键（foldToBet、callBet、threeBet…），openRatio / threeBetRatio / betSize / raiseSize 这四个连续量没有近因窗口：对手中途把 3bet 从 21.5bb 改成 5.5bb，读数要等全样本收敛才会动，默认通道（3bet 小尺度 -> 放宽跟注）就一直不生效。本版给这四个键各加一个同 ρ 的指数加权均值窗口，用相对偏离 |窗口均值 − 模型均值| / max(|两者|) 超过 0.25 判定跳变，并要求该键证据超过先验 16 次观测（把「先验 -> 真实值」的初始收敛和「对手改打法」分开），触发后把该键的均值换成窗口均值、强度重置为 先验+20。验收（同副牌同随机流逐手配对，每格 8 会话 × 4000 手，切换点第 1400 手，只统计切换后）：大 3bet 转小 3bet +7.0±1.4、小 3bet 转大 3bet −0.4±0.9、大而紧转小而宽 +4.1±1.5、小而宽转大而紧 −1.1±1.2 bb/100；静态对手 sizeB55 / sizeB215 / sizeB14 / tag 逐手 0.00（0 手不同）。代价：默认打开的尺度通道只有「小 3bet -> 放宽」一侧，测试台里对着大 3bet 放宽也是赚的（强行加宽 vs sizeB215 +14.5±4.4），所以读数向上跟随的那两个方向要倒扣；另外读数要 2~3 次触发（约 500 手）才收敛。
